# First CSS Layout

A basic webpage layout designed with CSS as part of [The Odin Project](https://www.theodinproject.com/). 

This project focuses on practicing:

- CSS selectors and properties
- Styling the page layout and typography
- Positioning elements using Flexbox or Grid (depending on your approach)

## Project Features

- Simple layout with styled header, content, and footer
- Use of CSS for styling text, buttons, and images
- Basic layout design concepts

## Technologies Used

- HTML
- CSS
